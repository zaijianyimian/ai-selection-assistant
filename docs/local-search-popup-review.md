## 审查中修复的问题

- 真实桌面路径发现 GTK 首次显示时外框尺寸短暂为 0×0，导致位置告警和默认窗口管理器位置。已在选区捕获完成后显示，异步让出事件循环、最多等待 500 ms 获取有效尺寸，再以保留锚点定位；真实首次打开和边缘快捷键均通过。
- 监视器回退改为按需查询，避免成功命中锚点监视器时仍查询当前监视器。
- 版本锁文件只更新应用自身；已核对 Cargo/npm 依赖版本与前一个提交一致。
- 手动验收数据库表说明更新为包含 FTS 内部表，未误称只有四张表。

## 原修复回归

原设置补偿/恢复、Secret Service、真实快捷键冲突、旧任务记忆 epoch、设置草稿/外部更新、结果 requestOptions 与恢复门控测试均保留并通过。新增索引没有使失败保存清空画像；原生失败前后完整 memory snapshot 相同。全部凭据是临时 fixture，模型 HTTP 仅访问测试脚本的 localhost 服务。
