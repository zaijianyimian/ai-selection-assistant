# v0.2.0 — 本地术语检索与附近翻译浮窗

本版统一交付设置恢复、结果显示和 Linux 依赖修复，以及本地检索、紧凑浮窗新功能。

- 术语记忆支持关键词与模糊相关搜索，覆盖词条、译名、领域和独立词义。多关键词 AND、中文短查询、字面标点、稳定分页和轻微英文错拼；使用 SQLite 全文索引/LIKE/词形匹配，不下载额外模型、不调用模型服务。模糊模式最多合并 1500 候选，不是向量语义理解。
- X11 快捷键在鼠标触发位置旁打开 440×600 翻译浮窗，屏幕边缘自动翻转/限位。选区先捕获，位置使用鼠标锚点近似；首次 GTK 映射的零尺寸问题已修复。长译文可滚动，复制、输入和术语反馈保留。
- Wayland 复用同一浮窗，沿用同次运行由合成器管理的手动位置，并显示限制提示；不承诺跨重启位置恢复。
- 设置保存失败时补偿凭据/快捷键/配置并保留记忆与画像；需要恢复时阻止模型请求，明确重存或删除凭据后解除。外部设置更新保留未保存草稿，旧译文保留原请求的语言和术语选项。
- DEB 从最终 ELF 生成版本依赖并再次验包；达到或超过 30,000,000 字节即拒绝。

## Linux 安装

附件 `ai-selection-assistant_0.2.0_amd64.deb`：**12,762,438 字节（约 12.76 MB）**。

基于 Ubuntu 26.04 amd64 构建并实装启动验证，要求 libc6 >= 2.39 及 DEB 中声明的 WebKitGTK/GTK 等原生库。Ubuntu 22.04 的 libc6 2.35 已实测被依赖约束拒绝；其他发行版需满足完整依赖，不能只依据 libc 版本判断兼容。桌面应用不需要 Node、Rust、Python 或数据库服务。

升级前从托盘退出旧实例。下载 DEB 与 SHA256SUMS 后，在下载目录运行：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./ai-selection-assistant_0.2.0_amd64.deb
```

SHA-256：`92cdcabfe8ac230d15f0773caa161008cef0a3da053e73939a726c594a3bb95f`。
