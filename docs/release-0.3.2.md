# v0.3.2 — 多端同步、GNOME 快捷键与显示修复（预发布）

发布日期：2026-10-17。桌面附件为 Linux amd64；本次未构建新的 Windows 安装包。真实 GNOME Wayland 人工验收尚未完成，因此本次标记为预发布。

## 更新

- 自托管多端同步：提供独立 VPS 服务，支持术语、出现记录、熟悉程度，以及外观、目标语言和解释风格；包含离线队列、冲突处理、设备撤销和删除传播。默认关闭；模型 Key、原文和完整译文不参与同步。
- GNOME Wayland：增加可主动启用的持久系统快捷键，固定命令转发至现有实例或冷启动；展示实际绑定，保留系统中的外部修改，并提供重新应用、停用和失败恢复。
- 修复 Ubuntu WebKitGTK 下设置下拉框文字偏下、中文裁切的问题；检查多种缩放比例和深色模式。
- 应用及托盘改用新的图标。

## 安装与使用

下载 `ai-selection-assistant_0.3.2_amd64.deb`，先退出旧实例再升级：

```bash
sudo apt install ./ai-selection-assistant_0.3.2_amd64.deb
```

DEB 为 13,603,386 字节，低于 30,000,000 字节。基于 Ubuntu 26.04 构建；要求 libc6 >= 2.39 及包内声明的 WebKitGTK、GTK、wl-clipboard、libglib2.0-bin 等依赖。不适用于 Ubuntu 22.04 的预编译安装。

Wayland 始终先 Ctrl+C 复制文字，再按快捷键。GNOME 用户可到「偏好设置 → 翻译偏好」保存组合键并启用系统快捷键。它不会自动获取其他应用的选区坐标；浮窗保留本次运行中的手动位置。

同步服务的源码、Compose 部署文件和预构建 amd64 Docker 镜像独立提供，不进入桌面 DEB。服务器代码与此前本地验证的 0.3.0 同步服务相同，镜像随本次发布标记为 `asa-sync-server:0.3.2`。使用 release 附件的部署说明；不要把模型 API Key 或 VPS SSH 密码当作同步密码。
