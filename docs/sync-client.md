# 客户端同步实现与验收

`src-tauri/src/sync/` 使用现有 SQLite actor，不在网络请求期间持有数据库事务。首次启用先创建私有 v1 备份，单事务创建 v2 的 `sync_state` 侧表。该表存储连接身份、两条独立 cursor、规范术语映射、事件去重 ID、逐字段远端版本、outbox、冲突、inbox 与非秘密的偏好提交意图。现有 terms/events 整数 ID 不变，搜索索引仍在本机派生。

连接绑定规范 URL、workspaceId、historyId、deviceId，凭据使用独立 keyring service `io.github.ai-selection-assistant.sync`。新连接使用新随机凭据项，成功发布前不覆盖旧凭据；失败补偿删除临时项并尽力撤销服务端临时设备，清理失败明确提示恢复错误。崩溃导致的未引用临时项永远不会被当成已接受连接使用。密码仅用于一次认证，前端 finally 清空，不保存在配置、数据库或错误里。模型 Key 项保持独立。

本地记忆写入和 outbox 在同一事务提交。上传前持久标记已发送，含歧义的操作 ID 和载荷不改变；同字段后续本机编辑等待前一个收据，再更新未发送基线。服务器明确拒绝的冲突单独保留，其他记录以原 ID 重组提交。用户保留本机时创建新操作，用最新已知远端版本提交，再有并发则再次冲突；采用远端仅应用允许的字段或当前熟悉程度。时钟只影响重试和出现时间，不选择冲突胜者。

每轮先拉偏好和记忆，再扫描本地、上传、再次拉取。身份准备和本地队列可在首次拉取前持久化，但远端删除/reset 在上传前先作废旧变更。每条流固定 until，页内变更与 cursor 原子提交。记忆暂停不前进其 cursor，也不上传；偏好独立前进。URL/工作区/history 改变需新的明确基线选择，旧队列不转移。禁用/重启连接的 session 代次使旧请求无法写回，即使用户迅速重新启用也不接受旧响应。

本地偏好保存沿用原有 settings_commit 协调器：先保存仅含三项偏好的持久意图，配置发布与 outbox 通过 actor 事务协调。失败恢复原配置并撤销意图；重启只在已保存文件匹配意图时补做队列。远端偏好先进入 durable inbox，持有设置锁并在 actor 事务中校验 session 后 patch 文件，成功才清除 inbox。文件已发布但确认失败可重放；发布不回写 outbox，避免回声。隐私、快捷键、模型配置和 Key 不经远端 patch。

手动/原生验收：

1. 升级后不开同步，翻译、关键词/模糊搜索照常；查看数据库仍是 v1。
2. 测试连接后密码框为空，服务没有新增设备；登录后后台仍关闭，界面不返回令牌。
3. 两台设备积累同词/异义词，立即同步后各自本机 ID 可不同，计数按事件并集合并。
4. 断网编辑并重启后恢复；同字段冲突分别选择本机和远端，其他记录继续。HTML 形式的文本只作为文字显示。
5. 关闭术语记忆，另一设备新增或删除；偏好继续变化，术语 cursor 不动。重新开启先处理删除/清空。
6. 设置窗口保留未保存草稿，另一窗口/同步修改已保存偏好，草稿不被覆盖；点击重载才更新。已有译文仍标明请求时语言。
7. 删除术语明确显示全设备范围；全局清空必须勾选确认。取消不操作；仅本机清空须先断开。
8. 撤销设备后停止自动认证重试；轮换密码保留数据。恢复服务器备份后重新登录并确认新 history 基线。
9. 检查主窗口、浮窗、托盘和系统启动器均使用图片图标。X11 浮窗近选区结束点；Wayland 手动位置行为保持原有约定。

自动证据：协议 golden fixtures；服务器事务/分页/认证/删除/配额测试；客户端实际本地 HTTP 服务与两个 actor 数据库测试；设置协调器故障注入；Vue 控件、草稿与转义测试；隔离 X11 WebDriver 和容器备份恢复演练。测试中所有密码/Key/术语均为专门夹具，不调用真实模型或真实 VPS。
