# Tasks

## 1. 用量类型、解析与覆盖规则

- [x] 1.1 新增独立 usage 类型，区分 operation、HTTP attempt、用途、统计 generation、已知/未知/待完成状态及本地缓存来源。验证：类型单测区分无历史、明确零、未知和零次请求的缓存命中。
- [x] 1.2 实现标准 input/output/total 与缓存输入、推理输出明细的容错解析，处理字段别名、子集关系和总量一致性。验证：表驱动测试覆盖完整、部分、null、负数、小数、溢出、冲突及重复别名，异常 usage 不使有效模型内容失败。
- [x] 1.3 实现 checked 整数累计、每字段覆盖计数和 operation 多尝试汇总；IPC 使用十进制字符串/null，前端安全格式化。验证：覆盖超过 JavaScript 安全整数、64 位边界及累计溢出，不出现舍入、回绕或把未知补零。
- [x] 1.4 为类型与解析模块补充字段映射、质量代码及非加法明细说明。验证：文档示例中输入 100、输出 30、缓存 20、推理 10 的总量仍为 130，并与解析测试一致。

## 2. 独立本地统计存储

- [ ] 2.1 基于现有 SQLite 新增 usage.sqlite3、独立 schema 和元数据、尝试收据、日汇总表，配置本地文件权限及有界访问队列。验证：临时目录测试首次初始化、再次打开与独立于术语库的读写，Linux 检查权限，Windows 检查实际文件创建/刷盘行为。
- [x] 2.2 实现 pending 登记及原子终结/聚合，重复终结为空操作；启动时将遗留 pending 终结为未知，清理超过 7 天的已终结收据且保留日汇总。验证：并发、重复事件、重启及收据清理测试保持计数一致，未完成收据不被误删，也不触发模型请求。
- [x] 2.3 实现今日、本月、累计和服务/模型/用途分组查询，保留累计起点及字段覆盖信息；分组查询参数化且默认 20、最多 100 组。验证：多类别、空历史、未知混合、分页及重启后查询结果一致，清理收据不改变累计。
- [x] 2.4 注入时钟并固定每次尝试开始时的本机日期、UTC 时间和偏移。验证：午夜、月界、夏令时、时钟回拨、时区改变及重试跨日测试无重复或历史挪动，不修改测试进程全局时区。
- [x] 2.5 实现原子 generation 清空和起算时间重置，丢弃旧 generation 的终结写入。验证：清空与并行请求竞争、重复终结及清空后的新请求测试，旧结果可保留本次用量但不能回填新累计，术语/缓存/设置/凭据不受影响。
- [x] 2.6 实现存储不可用、有界队列满、损坏和未来 schema 的非致命降级及完整性提示，并记录存储/保留策略。验证：故障注入保留原文件和有效结果，不自动重建、不阻塞请求至无限等待、不为记账重发模型请求。

## 3. 共用传输、操作快照与缓存

- [ ] 3.1 在共用 LLM 传输注入观察器，为四种用途捕获不可变配置及 operation 身份，每次真正发送 HTTP 时建立独立 attempt。验证：模拟服务检查翻译、未保存配置的连接测试、手动及自动分析的归类，更换全局设置不重分配在途用量，发送前被拒绝不创建 attempt。
- [x] 3.2 在 HTTP 状态处理、兼容降级及内容校验前捕获有效 usage，兼容重试逐次汇总。验证：模拟 HTTP 错误携带 usage、错误不携带 usage、格式/Temperature 降级和最终成功，断言实际请求次数、各尝试身份和已知/未知覆盖。
- [x] 3.3 为超时、取消、读取中断、超大响应、截断、拒绝、非法模型 JSON 及分析结果被丢弃保留终结快照。验证：对应故障用例保留已观察数字或未知标记，维持既有整体 deadline 和响应体上限，不引入额外网络重试。
- [ ] 3.4 将可选用量快照接入 Job、ConnectionTest、AnalysisStatus 及后端通知，成功与失败均可读取；前端通知只读不记账。验证：并行翻译/分析、主窗口/浮窗重复读取及乱序通知不会覆盖其他操作或重复累计。
- [ ] 3.5 保持 Translation 缓存不携带历史用量，为缓存命中生成零新增/零 attempt 快照，强制刷新正常记账。验证：输入、剪贴板和快捷键复用缓存时模拟服务调用次数不增加，双窗口不重记，清空缓存不清空统计，强制刷新增加实际调用。
- [x] 3.6 补充传输计量边界与无请求分支的开发说明。验证：每个模型调用入口均能对应用途及测试，统计查看/同步不经过模型计量，统计错误与模型结果错误保持独立。

## 4. 用量界面、说明与清空交互

- [ ] 4.1 在主窗口/浮窗的结果及错误区域呈现本次输入、输出、总量、覆盖和缓存来源，连接测试及最近手动/自动分析显示各自用量。验证：组件测试覆盖成功、失败、未知、缓存及并行操作，界面不会展示上一次操作的数字。
- [ ] 4.2 新增独立用量设置卡片，提供今日/本月/累计、起算时间、类别筛选/分页、覆盖和存储状态；接入后端 generation/revision 门禁。验证：组件/状态测试覆盖空历史、明确零、部分未知、重启读取、乱序快照和清空通知，多窗口结果一致。
- [ ] 4.3 新增二次确认清空流程，明确清空范围及不会取消已发请求，处理取消、提交失败和旧请求返回提示。验证：交互测试断言取消无写入、确认只调用统计清空、旧结果不回填，模型配置未保存时也不被清空动作意外保存。
- [x] 4.4 添加离线可读的 Token 使用说明及用户文档，说明字符差异、提示词/个性化上下文、服务端缓存、观测范围、日期归属、未知和账户额度/金额的区别。验证：检查不出现余额、金额估算或精确节省量承诺，关闭网络后说明和历史统计仍可阅读。
- [ ] 4.5 调整窄窗、明暗主题、换行与键盘访问，确保用量不遮挡复制/刷新等主要操作。验证：主窗口和浮窗视觉检查并保留截图，键盘可完成筛选、阅读说明及取消/确认清空。
