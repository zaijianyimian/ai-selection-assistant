# Why

每次翻译的术语目前都会丢失，模型无法使用用户确认的解释偏好。增加可控制的本地术语记忆，让后续解释结合相关术语和用户反馈，同时保持原文不落盘。

## What Changes

- 增加默认关闭的术语记忆；只保存术语、领域、独立词义及出现记录。
- 增加本地记忆页面、搜索、删除、清空与熟悉程度反馈。
- 增加手动模型分析和可选自动分析（应用运行时，每日检查，有至少 20 条新增记录）；使用用户配置的 API。
- 保存有版本的分析结果；以受限数据辅助后续解释，显式偏好和反馈优先。
- 术语展示、记忆、个性化、自动分析分别控制；连接测试不进入记忆。
- 更新隐私提示及 Windows/Ubuntu 验收说明；不保存原文、完整译文或 API Key。

## Capabilities

### New Capabilities
- `term-memory`: 本地术语、出现记录、用户反馈和数据删除。
- `memory-analysis`: 手动与应用内自动分析、版本及失败恢复。
- `personalized-explanations`: 有限上下文与显式解释偏好。

### Modified Capabilities
无已发布主规格；本变更在 foundation-mvp 的不保存翻译历史约束上增加用户主动开启的术语数据例外。

## Impact

Rust 增加 SQLite 工作线程、分析调度和 Tauri commands；模型响应增加独立词义字段。Vue 增加记忆页面和反馈交互。引入 bundled SQLite，不增加服务器、向量库或账号。
